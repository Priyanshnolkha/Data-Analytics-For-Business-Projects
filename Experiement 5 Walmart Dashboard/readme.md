# 📊 Walmart Sales Dashboard (Power BI)

## 📌 Project Overview

This project presents an **interactive Sales Performance Dashboard** built using **Microsoft Power BI** based on the **Walmart Sales Dataset**. The dashboard helps business users analyze sales performance, profit, product categories, and yearly trends to support data-driven decision-making.

This project was developed as part of the **Data Analytics for Business - Weekly Assignment 5** at **Alliance University**.

---

## 🎯 Objective

The objective of this dashboard is to:

- Monitor Total Sales, Profit, and Quantity Sold
- Analyze product category performance
- Compare yearly sales and profits
- Filter reports by location and time
- Enable interactive business insights

---

## 🛠️ Tools & Technologies

- Microsoft Power BI Desktop
- Microsoft Excel / CSV
- Power Query
- DAX (Data Analysis Expressions)

## 📈 Dashboard Features

### KPI Cards

- Total Sales
- Total Profit
- Total Quantity Sold

### Interactive Filters

- City
- State
- Category
- Year
- Month

### Visualizations

- Profit by Category (Column Chart)
- Sales by Category (Bar Chart)
- Profit by Year (Donut Chart)
- Sales by Year (Pie Chart)
- Category-wise Sales, Profit & Quantity (Table)

---

## 📊 Key Insights

- Copiers generated the highest profit among all categories.
- Bookcases and Machines recorded comparatively lower profits.
- Sales remained consistent across multiple years.
- Office products contributed significantly to overall revenue.
- Interactive slicers allow region-wise and time-wise performance analysis.
